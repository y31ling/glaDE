第一部分：引力透镜是怎么"算"出来的

1.1 光的偏折与三个角色

广义相对论告诉我们：质量使时空弯曲，光沿弯曲时空中的"直线"（测地线）传播，于是从远处看，光线像是被大质量天体"折弯"了。对一个质量为 M 的点质量，光线以瞄准距离 b（光线离天体最近时的距离）掠过时，偏折角为

α^=4GMc2b

这是牛顿引力估算值的两倍——多出的一倍来自空间弯曲本身。对星系尺度的天体，这个角非常小，以角秒（arcsec，记作 ″）计：1″=1/3600 度。本报告的一切长度其实都是天球上的角度，单位角秒。

一个引力透镜系统有三个角色，按距离排开：

观测者 ●———————————— 透镜星系 (z_l = 0.5) ———————————— 背景源星系 (z_s = 2)
 (望远镜)              (使光偏折的质量)                  (被观测的遥远天体)

z 是红移，可以粗略理解为"距离的标签"：z 越大越远。背景源发出的光经过透镜星系附近时被偏折，观测者于是看到位置移动、形状扭曲、甚至一个源变成多个像或一个环。

1.2 两个平面：image plane 与 source plane

这是初学者最容易混淆、又最重要的一对概念。两者都是天球上的二维角坐标系，不是空间里真实的两块平面：

  • 像平面（image plane）：你的望远镜实际看到的天空。坐标记作 θ=(θx,θy)。观测图像上的每个像素对应一个 θ。
  • 源平面（source plane）：假如把透镜星系拿走，背景源本来会出现在天空上的位置。坐标记作 β=(βx,βy)。它是"未被透镜扭曲的世界"。

两者之间由透镜方程（lens equation）联系：

β=θ−α(θ)

含义：你朝方向 θ 看，看到的那束光其实来自源平面上的 β 位置；α(θ) 是约化偏转角（reduced deflection angle）——真实偏折角 α^ 乘上一个距离比例因子 DLS/DOS（透镜到源的距离 / 观测者到源的距离），使方程里所有量都是同一坐标系下的角度。

图 1 把 1.1–1.2 节的三个角色与三个角摆进同一张图，透镜方程就是从图上直接读出来的。三步推导：

  1. 小角度近似：真实系统里 θ、β、α^ 都是角秒量级（约 10−6 弧度），所以"横向位移 = 角度 × 距离"精确成立；
  2. 在源平面上读横向距离：沿 θ 方向回望与源平面交于"视位置"，它偏离光轴 θDOS；源的真实位置偏离光轴 βDOS；两者之差正是偏折在源平面上造成的补偿量 α^DLS（偏折发生在透镜平面，到源平面还要传播 DLS，故乘 DLS 而非 DOS）。于是
θDOS=βDOS+α^DLS

3. 两边除以 DOS，并把矢量方向补回来：

β=θ−DLSDOSα^(θ)≡θ−α(θ)

括号里的组合 (DLS/DOS)α^ 就是上文的约化偏转角 α——"约化"约掉的正是这两段距离。

两个易错点：① 这些 D 是宇宙学的角直径距离（"角度 × 距离 = 横向物理尺寸"的换算系数），在弯曲膨胀的宇宙里不满足加法：DOS≠DOL+DLS，所以 DLS 必须由两个红移单独算出；② 图中为了看清把角画到了几十度，真实的强透镜里三条线几乎重叠——这也是小角度近似好到不用怀疑的原因。

一个关键的不对称性，决定了整个计算的方向：

  • 给定 θ，求 β：直接代公式，一次算完。每个观测方向只对应唯一的源位置。
  • 给定 β，求 θ：要解方程，且可能有多个解——这正是"多重像"：源平面上同一点的光，可以沿几条不同路径到达观测者，在像平面上呈现为几个像。

所以数值计算总是"反着来"：从像平面出发，逐像素反算回源平面（称为反向光线追踪，inverse ray-shooting）。这也是为什么"从 image plane 到 source plane"的方向在代码里无处不在。

1.3 从质量分布到偏转角：透镜势、会聚度

星系不是点质量。在"薄透镜近似"下（透镜的厚度远小于各段距离），把透镜星系的全部质量沿视线方向压扁到一张平面上，得到面密度 Σ(θ)：单位投影面积内的质量。

引入一个无量纲的量——会聚度（convergence）：

κ(θ)=Σ(θ)Σcr,Σcr=c2DOS4πGDOLDLS

Σcr 叫临界面密度，是由三段距离组成的常数（DOL：观测者到透镜；DOS：观测者到源；DLS：透镜到源）。κ≳1 的区域"够密"，能产生多重像——这就是强引力透镜。

再引入透镜势（lens potential） ψ(θ)：一个定义在像平面上的二维标量场，扮演"引力势的投影版"。它满足二维泊松方程（"二阶导数之和 = 源"形式的方程；这里 ∇2ψ=ψxx+ψyy，即两个二阶偏导之和），且它的梯度（对两个坐标的一阶偏导组成的向量，指向函数增长最快的方向）恰好就是偏转角：

∇2ψ=2κ,α=∇ψ,i.e.αx=∂ψ∂θx,  αy=∂ψ∂θy

于是计算链条是：质量模型 → κ(θ) → ψ 或直接 α(θ) → 透镜方程。多个透镜成分（比如一个暗物质晕加一个恒星成分）时，势可以线性叠加，所以 α、κ 等都直接相加。

1.4 放大率、雅可比矩阵、临界线与焦散线

透镜不仅移动像的位置，还改变其形状与亮度。看透镜方程的局部线性化：在某点 θ 附近，微小位移 dθ 映射到源平面的微小位移 dβ，两者由一个 2×2 矩阵联系——雅可比矩阵（Jacobian matrix） A（"多元函数的一阶导数矩阵"，描述局部的线性映射）：

A=∂β∂θ=(1−ψxx−ψxy−ψxy1−ψyy)=(1−κ−γ1−γ2−γ21−κ+γ1)

这里 ψxx=∂2ψ/∂θx2 等是势的二阶偏导；由二阶偏导组成的矩阵称为海森矩阵（Hessian matrix），描述曲面的局部弯曲程度。物理上把它们重组为：

κ=12(ψxx+ψyy),γ1=12(ψxx−ψyy),γ2=ψxy
  • 会聚度 κ：各向同性的"整体放大/缩小"；
  • 剪切（shear） γ1、γ2：各向异性的"拉伸压扁"，把圆变成椭圆。

放大率（magnification）是面积比。一小块源在像平面上占据的立体角（立体角：天球上一小块区域所张的"角面积"，可理解为二维版的角度）是它在源平面立体角的 μ 倍：

μ=1detA=1(1−κ)2−(γ12+γ22)

引力透镜有一条极其有用的守恒律——面亮度守恒（surface brightness conservation）：透镜不创造也不吞噬光子，单位立体角接收到的亮度（面亮度）不变。所以：

像平面上位置 θ 的像素亮度 = 源本身在 β(θ) 处的面亮度。

像变"亮"只是因为它占据了更大的立体角（μ 倍面积 × 相同面亮度 = μ 倍总流量）。这条守恒律就是第 1.5 节算法的全部物理依据。

临界线（critical curve）：像平面上 detA=0 的曲线，形式上 μ→∞。焦散线（caustic）：把临界线通过透镜方程映到源平面得到的曲线。源跨过焦散线时，像的数目发生 ±2 的突变。当源几乎正对透镜中心时，像被拉成一个环——爱因斯坦环（Einstein ring）。

对本报告最要紧的一点是：临界线附近，一切都极端敏感。那里 (1−κ)2≈γ12+γ22，detA≈0，一个位于分母上的小量。κ、γ（即 ψ 的二阶导）里任何微小的数值误差，都会在 μ 和局部映射里被急剧放大。后文的条纹恰恰出现在亮环（高放大率区）上，不是巧合。

1.5 扩展源成像 = 逐像素反向光线追踪

"扩展源（extended source）"指有可分辨大小的源（一个星系），区别于按点处理的"点源"（类星体、超新星）。给定透镜模型和源的面亮度分布 S(β)，生成模拟观测图像的算法就是把 1.2–1.4 节串起来。对像平面上的每个像素中心 θ：

  1. 计算 α(θ)　←　质量模型积分，本报告的主角；
  2. β=θ−α(θ)　←　透镜方程；
  3. 像素值 =S(β)　←　面亮度守恒。

本次复现的图像是 4000×4000 像素，也就是这套流程要执行一千六百万次。第 1 步对某些模型没有解析公式、必须数值积分——一切问题由此而起。

第二部分：glafic 中每一步如何运算

2.1 glafic 是什么

glafic 是 Masamune Oguri 编写的公开引力透镜软件（C 语言），可以正向模拟（给模型出图像）也可以反演拟合（给观测数据求模型）。GLADE 在 glafic2/ 内置了它的 2.1.14 版源码并做了少量本地修改（详见第四部分）。使用方式是写一个 .input 文本文件声明宇宙学参数、透镜成分、源成分，再执行命令，如 writeimage（渲染透镜化的扩展像并存为 FITS 文件——天文学通用的图像格式）、writecrit（输出临界线与焦散线）、findimg（解点源的多重像位置）。

2.2 从模型到偏转角：27 个透镜模型与三种实现路线

glafic 内置 27 种透镜质量模型（mass.c:10-39 的名字表），总入口 lensmodel()（mass.c:69-95）把各成分的贡献线性叠加（mass.c:354-367 lensmodel_sum，就是 αx、αy、κ、γ 逐项相加——对应 1.3 节"势可叠加"）。本案涉及两个模型：

NFW 轮廓（Navarro–Frenk–White）：数值模拟中暗物质晕的标准密度轮廓，

ρ(r)∝1(r/rs)(1+r/rs)2

由质量 M 和聚集度（concentration） c（描述质量向中心集中的程度）两个参数描述。其圆对称版的 κ、α 有解析闭式（mass.c:968-1001）。

Sersic 轮廓：描述星系恒星成分的标准亮度/质量轮廓。glafic 把它当作面密度使用：

κ(ξ)∝exp[−bn(ξre)1/n]

re 是有效半径（包含一半总光/质量的半径），n 是 Sersic 指数：n=4 即经典的 de Vaucouleurs 轮廓（椭圆星系、星系核球），n=1 是指数盘。bn 是使 re 恰好"包一半"的配套常数，代码用 Ciotti & Bertin 的级数近似（mass.c:2065-2080）：

bn≈2n−13+4405n+⋯

代码里的无量纲核只有几行（mass.c:2118-2125），即 κ(x)=exp(−x1/n)：

double kappa_sers_dl(double x)
{
  double xx;
  xx = pow(x, 1.0 / n_sers_sav);
  return exp((-1.0) * xx);      /* κ(x) = exp(−x^(1/n)) */
}

圆对称为什么容易：二维积分塌缩成一维公式

先把"难"的基准摆出来。对一般的面密度分布，由 ∇2ψ=2κ 解出的偏转角是一个二维积分——每个场点都要对整张平面求和：

α(θ)=1π∫κ(θ′)θ−θ′|θ−θ′|2d2θ′

若每个像素都老老实实做这个二维积分，4000×4000 的图完全不可行。圆对称是第一根救命稻草，其数学内核与静电学的高斯定理（或牛顿的壳定理）完全相同。把 ∇·α=2κ 在半径 θ 的圆盘上积分、用散度定理把面积分化成环路积分：

∮|θ′|=θα·n^dl=∫∇·αdA=2∫θ′<θκdA

对称性说 α 处处沿径向、模长只依赖 θ，环路积分左边就是 2πθα(θ)，立刻解出

α(θ)=2θ∫0θκ(θ′)θ′dθ′≡θκ¯(θ)

（κ¯(θ) 是 θ 以内的平均会聚度。）这一行浓缩了三件事：① θ 以外的质量完全消失——外部圆环对内部的引力恰好抵消（壳定理）；② θ 以内的质量可以全部当作挤在中心的一个点；③ 方向永远指向中心。二维积分塌缩成一维积分，而且这个一维积分只依赖一个变量 θ——对常见轮廓要么能直接积出解析式，要么整个模型预先造一张一维表即可。三个算例，由浅入深：

算例 1：点质量。全部质量挤在中心，取 θE（爱因斯坦半径，即 κ¯=1 的半径）作单位，则 α=θE2/θ。透镜方程变成一元二次方程，直接给出两个像：

θ−θE2θ=β⟹θ±=β±β2+4θE22

代数字：θE=1′′、源偏 β=0.3′′ 时，θ+=1.161′′、θ−=−0.861′′——透镜两侧各一个像。这就是"多重像"的最小工作模型。

算例 2：奇异等温球（SIS）。面密度按 1/θ 下降，积分后偏转角是常数：

κ(θ)=θE2θ⟹α(θ)=2θ∫0θθE2dθ′=θE

|β|<θE 时两像位于 θ=β±θE。一次初等积分，全部解析。

算例 3：本案的 Sersic 轮廓（圆对称版）——从 κ 到代码里那行不完全 Γ 函数。glafic 的无量纲 Sersic 核是 κ(x)=e−x1/n（2.2 节开头的 kappa_sers_dl；x=ξ/s，标度长度 s=rebn−n）。代入一维公式的分子，换元 t=x′1/n（即 x′=tn、dx′=ntn−1dt）：

∫0xe−x′1/nx′dx′=n∫0x1/nt2n−1e−tdt=nγ(2n,x1/n)

γ 是下不完全 Γ 函数。除以 x/2 并改写成规格化形式 P(a,z)=γ(a,z)/Γ(a)（利用 2nΓ(2n)=Γ(2n+1)）：

α1D(x)=2xnγ(2n,x1/n)=Γ(2n+1)P(2n,x1/n)x

这正是 glafic 里现成的那个函数——逐字对应：

double dphi_sers_dl(double x)   /* mass.c:2136-2143 */
{
  double xx;

  xx = pow(x, 1.0 / n_sers_sav);

  return gam2n1_sers(n_sers_sav) * gsl_sf_gamma_inc_P(2.0 * n_sers_sav, xx) / x;
}                               /* = Γ(2n+1)·P(2n, x^(1/n)) / x */

代入本案数字（把 sers 成分的椭率暂设为 0）：n=4⇒b4≈7.6692，s=reb4−4≈2.800×10−4′′。在条纹点 θ=(−0.71′′,0.42′′)，圆半径 r=0.8249′′，无量纲半径 x=r/s=2945.7：x1/4=7.367，P(8,7.367)=0.4558，α1D=40320×0.4558/2945.7=6.239；乘上由质量与 Σcr 决定的振幅（0.06215′′）得 |α|=0.38773′′。用真实 glafic 对这个圆对称模型执行 calcimage，输出 α=(−0.33372′′,+0.19741′′)：模长 0.38774″、方向严格指向中心（αx/αy=−0.71/0.42 逐位一致）——公式与代码闭环。整个计算只花一次不完全 Γ 函数求值。顺带一提：椭率 0.2 的椭圆版在同一点给 0.3887″，与圆版只差 0.3%——椭圆改变的不是答案的量级，而是拿到答案的代价。

椭圆为什么难——以及为什么还剩一条一维通道

真实星系是椭圆的（偏离圆的程度用椭率 e=1−短轴/长轴 描述，e=0 是圆；轴比 q=1−e）。把等密度线换成椭圆（κ=κ1D(ξ)，ξ 是椭圆半径）后，上面的推导在两处同时断裂：高斯环路积分 ∮α·n^dl 依然等于 2×内部质量，但对称性没了——α 不再沿径向、模长沿环变化，一条环路方程解不出一个矢量场；"内部质量集中到中心"的图像也随之失效。

但 19 世纪的位势理论留了一条活路（Newton 的椭球壳定理；Schramm 1990 引入透镜领域）。把椭圆密度切成一族同心相似椭圆薄壳（homoeoid），两条精确结论：① 薄壳在其内部不产生任何引力——壳定理的椭圆版依然成立，所以场点外侧的壳层照样"消失"；② 薄壳对外部一点的引力有闭式表达——只是方向不再指向中心，且随壳层大小变化。于是场点处的偏转 = 对内部壳层逐层求和。把壳层用参数 u∈(0,1] 标记（u→0 是中心，u=1 恰好是穿过场点的等密度椭圆；2.3 节的 ζ(u) 随 u 单调增，就是"第 u 层壳的椭圆半径"），逐壳叠加就是 2.3 节的一维积分族 Jn。这就是"椭圆密度还能算"的全部秘密：二维积分没有塌缩成一个一维函数，但塌缩成了每点一族一维积分。

代价要看清楚：圆情形的 α1D(·) 是单变量函数——每个模型解析求一次、或预先造一张一维查找表，此后每个像素只是"查表"；椭圆的 Jn(x,y) 是货真价实的二维函数（x、y 不能合并成单个椭圆半径），没有任何一维表能覆盖它，只能在每个场点现场做数值积分。本案 4000×4000 像素、每点 2 个 J 积分——3200 万次自适应 Romberg，这就是 2.4 节的全部舞台。两种机制的衔接还能数值验证：令 q→1，J 积分严格退化回圆公式

Jn|q=1=∫01κ(ur)du=2r2∫0rκ(s)sds=α1D(r)r

（本仓库实测 q=0.999999 时两边比值 1.0000006，见附录 B 的解剖脚本。）

glafic 对"怎么把圆轮廓变成椭圆"提供了三条路线，这个选择正是本案的分水岭：

路线一：椭圆势（elliptical potential）——便宜但略失真

把椭圆放进势里：取圆对称模型的一维势 ψ1D，直接把它的自变量换成"椭圆半径"

u=(1+ε)X2+(1−ε)Y2

（X、Y 是转到主轴——即椭圆长短轴方向——后的坐标；ε 即输入的椭率 e），即令 ψ(θ)=ψ1D(u)。这样 α、κ、γ 全部可以用链式法则从一维函数解析算出，无需数值积分。代码在 u_calc（mass.c:3006-3034，注释 "for elliptical potential"）一次性给出 u 及其一、二阶偏导 u[0..5]。模型名带 pot 后缀：nfwpot、serspot、hernpot 等。

代价：等势线是椭圆 ≠ 等密度线是椭圆。由 ∇2ψ=2κ 反推出的面密度在椭率较大时会呈现非物理的"哑铃／花生"形。所以它是快速近似，不是物理上最自然的选择。

路线二：椭圆密度（elliptical density）——物理但要数值积分

把椭圆放进密度里：κ(θ)=κ1D(ξ)，其中 ξ 是密度等值线上的椭圆半径。这物理上自然（星系的等亮度线就是近似椭圆），但势和偏转角再无闭式解——必须数值积分。glafic 采用 Schramm (1990)（另见 Keeton 2001）的经典结果：把二维积分化成一族一维积分（见 2.3 节）。走这条路的共 8 个模型：nfw、hern、pow†、gnfw、sers、tnfw、ein、king（模型名不带 pot 后缀的密度版）。

† pow（幂律）默认走 Tessore & Metcalf (2015) 的解析方法（开关 flag_pow_tm15，默认 1，glafic.h:198），只有用户手动置 0 才落入数值积分路线。

路线三：CSE 解析近似——用"可解析的积木"拼出椭圆密度

Oguri (2021, arXiv:2106.11464) 把 NFW 等轮廓展开成若干个 "cored steep ellipsoid"（CSE）基函数的线性组合，每个基函数的椭圆密度透镜量都有闭式解（app_ell.c:314-357）。模型名带 a 前缀：anfw、ahern、acnfw。既是椭圆密度、又完全解析、无数值积分。 记住这一点：复现输入里的 NFW 用的是 anfw，这就是"纯 NFW 图像完全干净"的原因。

2.3 Schramm 积分：J、K、I 家族（TOL_ROMBERG_JHK 名字的来历）

椭圆密度模型的核心数学是 glafic 手册 §A.2 的公式（Schramm 1990 的均质椭球壳分解；直觉：把椭圆质量分布看成一层层相似椭圆"壳"，积分变量 u∈(0,1] 遍历这些壳层，每层按当地的 κ 贡献引力）。设 q=1−e 为轴比（短轴与长轴之比）、(x,y) 为主轴系无量纲坐标（天球角坐标转到长短轴方向、再除以模型的标度长度——见代码中 bx、by 的构造），定义随 u 变化的椭圆半径

ζ(u)=u(x21−(1−q2)u+y2)

则透镜势及其各阶导数是三类一维积分的组合：

ϕ=q2I(x,y)ϕx=qxJ1(x,y)ϕy=qyJ0(x,y)ϕxx=2qx2K2+qJ1ϕyy=2qy2K0+qJ0ϕxy=2qxyK1

其中

I(x,y)=∫01ζ(u)α1D(ζ(u))u1−(1−q2)udu
Jn(x,y)=∫01κ(ζ(u))[1−(1−q2)u]n+1/2du
Kn(x,y)=∫01uκ′(ζ(u))2ζ(u)[1−(1−q2)u]n+1/2du

一句话总结：J 积分（被积函数是 κ）给偏转角；K 积分（被积函数是 κ 的导数 κ′）给二阶导（进而给 κ、γ）；I 积分（被积函数含 α1D，即圆对称模型的一维偏转角函数）给势本身。 宏名 TOL_ROMBERG_JHK 就是这一家积分的容差；顺带澄清：代码里其实没有叫 "H" 的积分，三个函数是 ell_integ_i/j/k，"JHK" 只是这个家族的统称标签。

代码与公式逐项对应（mass.c:3040-3154）：

double ell_integ_j_func(double u)              /* Jₙ 的被积函数 */
{
  equ = ell_qu(q_integ_sav, u);                /* equ = 1−(1−q²)u          */
  se  = sqrt(ell_xi2(u, equ));                 /* se  = ζ(u)（含 smallcore 软核防中心奇异）*/
  f   = ell_nhalf(equ, n_integ_sav);           /* f   = equ^(n+1/2)        */
  return func_sav(se) / f;                     /* κ(ζ) / (1−(1−q²)u)^(n+1/2) */
}

func_sav 是插进来的一维轮廓核——对 Sersic 就是上面那几行 exp(−x1/n)。以 kapgam_sers（mass.c:2159-2227）为例的组装：

j1 = ell_integ_j(kappa_sers_dl, 1);   bpx = q * bx * j1;    /* φx = q·x·J₁ → αx */
j0 = ell_integ_j(kappa_sers_dl, 0);   bpy = q * by * j0;    /* φy = q·y·J₀ → αy */
...
bpxx = 2.0*q*bx*bx * ell_integ_k(dkappa_sers_dl, 2) + q*j1; /* φxx：直接由 K 积分给出（同样是数值积分，但不走差分）*/

成本账：每评估一个像面点，需要 2 个 J 积分（偏转）；若还要 κ、γ，再加 3 个 K 积分；若要势（用于时间延迟：同一源的几个像沿不同路径传播、到达时刻有先后，其时间差可用来测量宇宙膨胀），再加 1 个 I 积分。每个积分都是一次自适应 Romberg 过程（见 2.4 节）。

还有一个后文要用的细节：积分驱动函数会按位置选择线性或对数换元（mass.c:2194-2201）——离透镜中心远（判据：代码变量 uu =1/(x2+y2)≤0.1，即无量纲圆半径平方的倒数）时被积函数集中在 u≈0 附近，改用 lnu 为积分变量。这是一处随位置突变的算法分支，记住它。

2.4 Romberg 积分：自适应、容差，以及被忽略的收敛状态

上面的 J、K、I 积分没有解析解，glafic 用 Romberg 方法数值求积。给不熟悉的读者三步讲清。

第一步——梯形法：把区间等分成小段，每段面积按梯形算。步长为 h 时误差按 h2 的幂级数展开：

E(h)≈C2h2+C4h4+⋯

第二步——步长减半 + Richardson 外推：把 h 减半再算一次。两个结果的误差主项都已知是 h2 形式，就可以线性组合把 h2 项精确消掉：

R=4T(h/2)−T(h)3

反复减半、反复外推，构成一张三角形表 R(i,j)，对角线 R(i,i) 对光滑函数收敛极快。

第三步——自适应停机：每加深一层，比较对角线的相邻两项，"变化足够小"就收工。

glafic 通过 GSL（GNU 科学计算库）实现。停机准则在 GSL 的 romberg.c 中：

err = fabs(Rc[i] - Rp[i - 1]);                    /* |R(i,i) − R(i−1,i−1)| */
if ((err < epsabs) || (err < epsrel * fabs(Rc[i])))
    return GSL_SUCCESS;                            /* 认为收敛，返回 R(i,i) */

即当

|Ri,i−Ri−1,i−1|<εabs或|Ri,i−Ri−1,i−1|<εrel|Ri,i|

时停止。glafic 的包装函数 gsl_romberg2（gsl_integration.c:113-140）传入 εabs=0、εrel=TOL_ROMBERG_JHK——纯相对容差：

TOL_ROMBERG_JHK 的准确含义：当 Romberg 表对角线的相对变化量小于它时，停止细分并接受当前值。 上游 glafic 定为 5.0×10−4，GLADE 内置版改为 1.0×10−5（glafic.h:375）。

三个隐患埋在这套机制里：

（a）误差是"估计"不是"保证"。 |Ri,i−Ri−1,i−1| 只是相邻两层的差，是启发式的误差代理。它偶尔过于乐观——两层碰巧接近不代表都接近真值。

（b）误差随位置呈"台阶"状——这是条纹的种子。 像素 θ 连续移动时，被积函数连续变形，但"需要细分到第几层才达标"是整数，只能跳变。设想像素 A 在第 6 层达标、隔壁像素 B 需要第 7 层：两点返回值的精度突然不同，偏转场 α(θ) 上叠加的误差就在 A、B 之间出现一个量级约 ε|α| 的台阶（ε 即容差）。这些层数切换的边界在像平面上构成一条条曲线；2.3 节末的"线性/对数换元分支"边界同理。真实的 α 场是光滑的，数值的 α 场却带着一圈圈看不见的"梯田"。

（c）不收敛时静默返回。 工作区上限 GSL_ROMBERG_N = 16 层（glafic.h:369）；用完仍未达标时 GSL 返回错误码 GSL_EMAXITER，但 glafic 把检查注释掉了（gsl_integration.c:130-135）：

/* if (gslstatus != GSL_SUCCESS){
   fprintf(stderr, "integration failed in gsl_romberg2\n");
   exit(EXIT_FAILURE);
   } */

欠收敛的结果被无声接受——正是"位置相关误差"最恶劣的来源之一。

2.4.3 把预言叠回真实图像：条纹的定量闭环

窄条内 J1 偏大 +2.42% 意味着什么？该处 Sersic 分量的 αx=−0.344′′（|αsers|≈0.39′′），于是 δαx≈+2.42%×0.344′′≈8.3 mas。两条传导链同时开动：

  • 直接位移：β=θ−α，污染列的 β 整体平移约 8 mas。源是 re=0.1609′′ 的 n=4 Sersic，环上像素映到源轮廓的陡峭段，对数斜率 |dlnS/dr|~b4/(4re)≈12/′′ 量级——亮度改变 ~10% 量级，与实测条纹深度 11.5% 同量级（方向投影与局部半径会调制系数，这里只做量级核对）。
  • 差分放大（2.5 节的放大器）：窄条边界两侧的列，差分分子一端污染、一端干净，ψxx 尖峰 = δαx/2h≈8.3×10−3/0.002≈±4.2（实测 ±4.18）——不是 2.5 节按容差承诺估出的 0.1，而是直接把近临界处量级 ~1 的真实 ψxx 整个淹没。窄条内部的列两端都污染、尖峰相消，差分反而近似正常——所以最黑的是窄条本身（β 平移主导），边界列则被海森矩阵搅乱。

最后核对形态的四件事：① 逐列吻合——预测污染列 1296–1298，真实差图该行条纹列正是 1296–1298（图 6 灰带）；② 近乎竖直——追踪窄条中轴（对角线交点）随 y 的漂移：y 从 0.34″ 走到 0.52″（180 行），中轴只从 −0.6966″ 漂到 −0.7064″（约 10 列），与竖直方向夹角约 3°，且在 y ≈ 0.50″ 处恰好穿过用户最初报告的列 1294；③ 左右成对——J 积分只通过 bx2 依赖 bx，窄条在 +0.70″ 处有严格镜像，即 |o| 的两竖；④ 1×10−5 的残纹——窄条只剩 0.07 像素宽，沿 150 行只能零星命中像素中心，与"0.38%、不可见"一致。

至此，3.4 节因果链的"种子"环节有了精确身份：不是均匀的容差台阶，而是第 3 层对角线相交造成的假收敛窄条——种子比容差承诺大 48 倍，放大器拿到的不是台阶而是断崖。层级台阶依然存在，但它是铺满全图的 ~10−5 背景；条纹的显影由窄条一手主导。

2.5 扩展像流水线 extend.c：两阶段，与一台误差放大器

现在看 writeimage 是怎么由上述材料拼出一幅图像的。流水线分两阶段。

阶段 A：把偏转角铺满整张网格。 ext_set_table（extend.c:42-147）对每个像素中心调用一次 lensmodel(tx, ty, pout, 1, 0)——注意第 4 参数 alponly=1，只算偏转角，不算二阶导——然后缓存进数组：

array_ext_def[k]      = pout[0];    /* αx，注意：以 float（单精度）存储 */
array_ext_def[k + nn] = pout[1];    /* αy */

对椭圆密度模型，这一步的每个 α 都出自 2.3–2.4 节的 Romberg J 积分，各自带着约 ε 量级的相对误差和"梯田"结构（存成单精度 float 又额外垫了约 10−7 的相对噪声底，量级远小于 5×10−4，此处非主因）。

阶段 A 后半：有限差分海森矩阵——放大器登场。 渲染需要每个像素的 ψxx、ψxy、ψyy（做放大率和亚像素映射，见阶段 B）。glafic 没有用模型自带的 K 积分二阶导（2.3 节明明有！alponly=1 恰恰跳过了它们），而是对刚缓存的 α 网格做中心差分（用左右邻点函数值之差除以间距来近似导数）（extend.c:135-142）：

/* phi_xx */  array_ext_mag[k]          = (axxp - axxm) / ddx;
/* phi_xy */  array_ext_mag[k + nn]     = (ayxp - ayxm) / ddy;
/* phi_yx */  array_ext_mag[k + 2 * nn] = (axyp - axym) / ddx;
/* phi_yy */  array_ext_mag[k + 3 * nn] = (ayyp - ayym) / ddy;

即

ψxx≈αx(x+h,y)−αx(x−h,y)2h

h=pix_ext 是像素尺度，本案 0.001″，故分母 2h=0.002″。用一个很小的数去除"两个几乎相等的大数之差"，是数值计算的经典险境：分子里真正的信号（α 的真实变化）约为 2hψxx~0.002（近临界处 κ、γ 都是 1 的量级——见 1.4 节——故 ψxx~1），而两端各自携带的积分误差却以 ε|α| 计。

代入本案数字。注意相对容差只作用于带 Romberg 积分的那个成分：条纹处 anfw 是闭式解、无积分误差，携带误差的是 Sersic 分量，其偏转 |αsers|≈0.39″（用内置 calcimage 在条纹位置实测；两成分合计 |α|≈0.86″）：

ε=5×10−4:δα~ε|αsers|≈5×10−4×0.39″≈2×10−4″,δα2h≈2×10−40.002≈0.1
ε=1×10−5:δα2h≈0.002

前者对 ψxx 而言是无量纲的 0.1——与近临界处量级约 1 的二阶导相比不可忽略；后者只是千分之二的小扰动。放大倍数就是 1/(2h)=500；当台阶两侧的两个差分端点误差恰好一正一负时（相邻列共享同一个被污染的采样，见 2.6 节的暗亮线成对机制），分子里的误差翻倍，等效 1/h=1000。这就是复现报告里"放大约 500–1000 倍"的出处。回想 1.4 节：条纹所在的亮环正是临界线附近，

detA=(1−ψxx)(1−ψyy)−ψxyψyx≈0,

一个 0.1 的伪 ψxx 足以彻底改写当地的放大率与局部映射。

（这一段是按"容差 = 真实误差"的承诺值做的量级估算。2.4.3 的实测解剖表明：条纹列所在的假收敛窄条内，种子实为 2.4%、ψxx 尖峰实为 ±4.2——比这里的估算凶得多；而窄条之外的背景台阶（实测 ~10−5）又比估算温和得多。承诺值恰好落在两者之间。）

顺带一提（与条纹无关的边界小瑕疵）：phi_xy 那行沿 x 方向取点、却除以 ddy；phi_yx 那行沿 y 方向取点、却除以 ddx。内部像素 ddx = ddy = 2h，结果无差别；仅在图像边界一侧取不到邻点时两者不等。

阶段 B：逐像素套透镜方程 + 渲染。 ext_set_image（extend.c:191-210）：

sx = x - array_ext_def[k]      * dis_fac_ext[ii];   /* βx = θx − αx（dis_fac 按源红移缩放 α）*/
sy = y - array_ext_def[k + nn] * dis_fac_ext[ii];   /* βy = θy − αy */
...
array_ext_img[k + ii*nn] = (float)sourcemodel(sx, sy, ii, pxx, pxy, pyx, pyy, pix_psf);

dis_fac_ext 是距离比（α∝DLS/DOS 依赖源红移，缓存按基准红移算好后按比例换算）。sourcemodel 落到 source_all（source.c:236-282），它拿着有限差分出来的 ψxx…ψyy 做两件事：

muinv = fabs((1.0 - pxx) * (1.0 - pyy) - pxy * pyx + imag_ceil);   /* 1/μ，判定是否需要细分 */
...
dsx = (1.0 - pxx) * dx - pxy * dy;    /* 亚像素点 (dx,dy) 经局部线性映射投到源平面 */
dsy = (1.0 - pyy) * dy - pyx * dx;
f  += source_sersic(x + dsx, y + dsy, ...) * hh * hh;   /* 5×5 亚采样取平均（贴近源心时 20×20）*/

亚像素点的映射正是雅可比矩阵 A 的局部线性作用：

(dsxdsy)=(1−ψxx−ψxy−ψyx1−ψyy)(dxdy)

这就是亚像素抗锯齿（anti-aliasing）：一个像素不是无穷小的点而是一个小方块，高放大率处它在源平面的"足迹"会盖住源的一大片，只取中心一点会产生锯齿伪影，所以把像素细分成 5×5 个子点、用局部线性映射逐点映到源平面取亮度再平均。足迹的形状完全由 ψxx…ψyy 决定——于是被污染的海森矩阵把足迹算错，像素平均出系统性偏低（或偏高）的亮度。误差沿"Romberg 层数切换边界"整列出现，便渲染成一条切割亮环的暗线。相邻列还会共享同一个被污染的 α 采样、在差分中一正一负——暗线旁常伴一条亮线。

（writeimage_ori 与 writeimage 是同一函数的 flag 区别：ori 直接令 sx = x、sy = y，即"不透镜"，把源画在同一网格上作对照。）

2.6 为什么恰好是"竖直"暗线、还成 |o| 形？

把线索拼起来：

  • 误差台阶的边界是像平面上的曲线。其具体形状由"该点的积分需要细分到第几层"决定，一般没有简单的解析描述（并非某条椭圆等值线那么简单）；但 2.4.2 的解剖给出了条纹处这条边界的精确身份——R(3,3)−R(2,2)的零交叉曲线（假收敛窄条的中轴）。实测它与竖直方向夹角仅约 3°、横跨 150 像素高度只漂移约 10 列（2.4.3），与差图 diff_STOCK5e-4_minus_GLADE1e-5.fits 中的形态一致。本案两个透镜的位置角 pa=0（位置角：长轴在天球上的取向角；pa=0 即主轴对齐坐标轴）、中心同在原点 (0,0)，整个系统左右镜像对称——所以误差边界左右成对出现。
  • 四行差分里，沿 x 取点的两行（ψxx、ψxy）在跨越一条近竖直边界时两端分属两侧、产生尖峰；沿 y 取点的两行（ψyx、ψyy）两端同侧、台阶相消。于是尖峰恰好整列聚集——呈竖直线段。
  • 只有叠在亮环（高 μ、近临界）上的那段才看得见：暗背景上再大的相对误差也没东西可"变暗"。

于是：左右各一条竖直短暗线 + 中间的爱因斯坦环 = 用户在 ds9（天文 FITS 图像查看器）里看到的 |o| 图案。

  1. 容差单调控制条纹（10−2 多条 → 5×10−4 一条 11.5% → 10−5 降至 0.38%，以 10−8 参考图为干净基线）：病灶在受 TOL_ROMBERG_JHK 管辖的积分，别无他处。
  2. anfw 单独完全干净：解析路线无 Romberg，反证病灶就是数值积分本身，而非 extend 渲染或源模型。
  3. sers 单独在同一位置有条纹但暗弱：条纹的"形"由 Sersic 的 Romberg 误差决定，条纹的"亮"靠 NFW 的高放大率亮环提供舞台。两成分叠加，误差（Sersic 的）遇上放大器与聚光灯（NFW 主导的近临界亮环 + 有限差分），伪影才显形。

3.4 根因链条（总结）

  1. 病灶：Sersic 椭圆偏转 = Romberg J 积分（相对容差 TOL_ROMBERG_JHK）。自适应停机使 α 场带上位置相关的"台阶"误差，δα~ε|αsers|；欠收敛还会被静默接受（gslstatus 检查被注释）。
  2. 放大：extend.c 用中心差分从 α 网格求海森矩阵（除以 2h=0.002″）。台阶变成 ψxx 尖峰，放大约 500–1000 倍；ε=5×10−4 时尖峰量级约 0.1（近临界处不可忽略）。
  3. 显影：source.c 亚像素抗锯齿用该海森矩阵定像素足迹与细分判据。近临界（detA≈0）处足迹被彻底算错，整列亮度系统性偏低。

最终结果：亮环上一条竖直暗线（|o|），深 11.5%（ε=5×10−4）/ 0.38%（ε=10−5）。

第四部分：5×10⁻⁴（上游默认）与 1×10⁻⁵（GLADE）的影响

4.1 谁在被影响：受波及的模型与功能

TOL_ROMBERG_JHK 只出现在 6 处调用（mass.c:3046-3111），全部在 J/K/I 积分驱动内。因此：

  • 受影响：8 个椭圆密度模型 nfw / hern / gnfw / sers / tnfw / ein / king / pow(仅当 flag_pow_tm15=0) 的一切输出——偏转角、κ、γ、势、放大率、由它们导出的像位置、时间延迟、以及扩展像渲染。没有"椭率为 0 就跳过积分"的捷径：即便 e=0，这些模型也照走 Romberg（想要快请显式改用 *pot 或 anfw 系）。
  • 不受影响：*pot 椭圆势系、CSE 系（anfw/ahern/acnfw）、解析等温系（sie/jaffe）、点质量、外部剪切/外部会聚等。（gnfw/ein 的径向内层积分另有独立容差 TOL_ROMBERG_GNFW =3×10−4 / TOL_ROMBERG_EIN =10−3，且默认用查表替代。）

4.2 对扩展像：条纹（本案主线）

上文已量化：5×10−4 → 11.5% 深、肉眼可见的伪影线；10−5 → 0.38%，约 30 倍衰减，沉入不可见。对科学工作的含义：

  • 用上游默认容差渲染的高分辨率扩展像里，近临界区域的形态可能带有百分之十量级的假结构——足以被误读成"子结构""吸积流"或让人白白追查观测流水线。
  • 对以像素为单位拟合扩展像的工作（GLADE 的 FITS 扩展源拟合正是逐像素 χ2——观测与模型的加权平方残差和），条纹级误差会给 χ2 面注入伪梯度，虽多数情形被观测噪声淹没，但近临界高信噪比数据下不可忽视。

4.3 对点源：毫角秒级的位置漂移

同一积分误差不经有限差分也会直接侵蚀点源计算（findimg 解透镜方程用的正是同一 α 与 K 积分二阶导）。仓库内部验证与致上游作者的信件记录了量化结论（manual/GLADE_Manual_en.md §10）：

  • 5×10−4：贴近临界线的像，位置可偏差至 约 5 mas（毫角秒），放大率偏差可观——因为临界线附近偏转误差被 |μ| 再放大。一次内部验证曾在（事后发现仍是 5×10−4 旧构建的）glafic 上测得单个 Sersic 成分的偏转误差最高约 46 µas，正对应毫角秒级的像移（memory.md §7）；
  • 10−5：位置精度进入 µas–mas 过渡带；
  • 10−8：与独立的 scipy 高精度参考（scipy 是 Python 科学计算库，此处指用其高精度积分例程独立实现的参考计算）基本严格一致。

对强透镜时间延迟宇宙学（用多重像的到达时间差测宇宙膨胀速率）、亚毫角秒天体测量（对像位置的超高精度测定）这类应用，5×10−4 显然不够；对常规的角秒级建模，它勉强够用——想必这就是上游默认值的取舍逻辑。

4.4 性能代价：为什么 GLADE 停在 10⁻⁵ 而不是 10⁻⁸

容差收紧 = Romberg 多细分几层。每加深一层，被积函数求值次数翻倍（第 16 层上限对应最多 215+1=32769 次求值/积分）。版本史清楚记录了权衡过程（Update.txt）：

  • V0.3 曾直接用 10−8——精度无可挑剔，速度代价明显；
  • V0.4.0/V0.4.1 回退到 10−5："精度与速度的折中：比旧值 5.0×10−4 更精确，又比 V0.3 的 1.0×10−8 快得多"；
  • 文档中唯一的量化数字：从 10−5 再收紧到 10−8，受影响积分慢约 2–4 倍。
  • 诚实声明：仓库里没有 5×10−4↔10−5 的直接计时对比；定性结论是 10−5 的开销远小于 10−8，而条纹与毫角秒问题已被压到不可见/可接受。

4.5 GLADE 的多层防线

  1. 头文件补丁（根本手段）：glafic.h:374-375 带注释 /* glade local override: tightened from upstream 5.0e-4 for accuracy (see Update.txt) */。这是编译期常数——没有运行时开关（无 .dat 键、无环境变量、无 API），改动必须重编译（cd glafic2 && make clean && make python，别忘了 Python 绑定 glafic.so 也要重建——历史上出过头文件已改成 10−5、旧 .so 仍是 5×10−4 的"构建状态陷阱"）。
  2. GPU 引擎天然免疫：GLADE 的 GPU 引擎 Rhongomyniad 用同一套 Schramm 公式，但以 256 节点固定 Gauss–Legendre 求积（另一类数值积分规则：在 256 个固定的优选采样点上加权求和）替代自适应 Romberg（Rhongomyniad/rhongomyniad/elliptical.py）——无停机判据、无层级台阶、无位置相关分支，误差光滑。对照 scipy 高精度参考的交叉验证表明 GPU 路径达约 10−9″ 精度，比 glafic 二进制更准；V0.5.0 发布前（V0.4.6 阶段）的 10−8 重编译交叉验证进一步证实此前 GPU↔glafic 的微小分歧是 glafic 侧的 Romberg 噪声（sers 偏差指标 2.7×10−4→1.3×10−6）。
  3. 验证器的明示：core/verify.py 在 glafic 与优化器损失有出入时输出说明性警告——"glafic 的椭圆 Sersic 偏转受 Romberg 容差限制，此差异是预期的，不是结果错误"，并以 scipy 精确参考为最终裁判。
  4. 10−8 交叉验证规程：tools/verify_gpu_models.py 文档化了"临时改 10−8 → 重编译 → 对比核对 → 恢复 10−5"的标准流程，用于每次发布前的高精度核对。
  5. 文档：用户手册（GLADE_Manual_zh.md/en §10）设专章记录此事；一个已知的历史遗留是 Rhongomyniad/README.md 与 constants.py 中仍写着 5×10−4 的失效镜像常数（无任何代码消费，勿被误导）。

4.6 给上游（glafic 作者）的建议（已在复现报告中分层列出）

  1. 立即可做：把 TOL_ROMBERG_JHK 默认值从 5×10−4 收紧到 10−5 或更紧——GLADE 实测条纹即随之消失；
  2. 根治（设计层）：extend.c 不要再用有限差分求海森矩阵——glafic 的 kapgam_* 本就能通过 K 积分直接算出 κ、γ（2.3 节；同样带约 ε 量级的积分误差，但不会再被除以 2h），改用它即可消掉约 1/h 的放大因子，让残余积分误差不再被放大成可见伪影；
  3. 诊断：恢复对 gslstatus 的检查，Romberg 不收敛时至少给出警告，而非静默返回欠精度值。

（背景：GLADE 项目与上游作者 Oguri 已有既往沟通——两个无关的 bug 已提交为 oguri/glafic2 issue #4、#5；一封含 TOL_ROMBERG_JHK 点源精度问题的信件草稿写于条纹发现之前，条纹本身尚未正式上报。）

4.7 结论

一条 150 像素长的暗线，牵出了一条完整的数值物理因果链：自适应积分的整数层级停机把光滑的偏转场刻上台阶（种子）；有限差分以 1/2h 放大台阶（放大器）；近临界的高敏感度和亚像素渲染把它显影在最亮的环上（显影液）。 三个环节缺一则不可见——解析的 anfw 无种子，粗像素或直接取 K 积分海森则无放大器，暗弱区域无显影。GLADE 把容差从 5×10−4 收紧到 10−5，以温和的 CPU 代价把种子削小 30–50 倍，同时以免疫的 GPU 引擎、scipy 参考核对与文档专章兜底。上游的根治之道则是釜底抽薪：用模型本就会算的 K 积分二阶导替换有限差分。
