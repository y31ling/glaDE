V0.4-ReUnit — Re-Unification

中文
- 重构核心：将原先分散、重复于 legacy/ 中的差分进化（DE）优化与作图代码，抽取为统一、与后端无关的 core/ 模块（legacy/ 保留为历史归档，新代码不再依赖它）。
  · core/optimize —— 单一 DE 优化器，同一套代码即可驱动 glafic(CPU) 或 Rhongomyniad(GPU)；主透镜与子结构（point-mass / NFW / King / p-jaffe …）可任意组合、混合优化。
  · core/plot —— 统一的三联图、临界曲线与迭代过程动画帧绘制。
  · core/format —— 全新的 .dat 配置格式与解析器（见下）。
  · core/translate —— glafic ↔ glade 双向翻译脚本（含命令行）。
- 全新 .dat 配置格式：贴近 legacy 的内联写法，新增 {下限, 上限} 标记“待优化”维度（裸数值即锁定），$float / $int 为待填占位符；质量类参数在 log10 空间搜索。多文件按区块合并、组件序号全局重排；缺失的基础量回退到默认值并提示确认。
- 完全重写 WebUI（webui/，旧 web/ 弃用）：顶栏两页 FindImage（默认）与 Editor；在 FindImage 选择 CPU / GPU / Glafic 与一个或多个 .dat 文件后运行；运行时新开一个真实终端并自动输入指令，WebUI 通过 SSE 实时回传该终端输出，每个任务独立目录——彻底解决并发问题。Editor 为类 VSCode 三栏（50px 图标栏 + 可拖拽侧栏 + Monaco 多标签编辑器，含保存/删除）；Explorer 管理 InputFiles（新建/打开/重命名/删除/导入/导出翻译）；Template 面板按光标插入带注释的预设片段。
- glafic ↔ glade 翻译：导入时优化矩阵中标记为 1 的参数转为 {v, v} 供手动微调；导出时 {下限, 上限} 取代表值（质量类取几何平均），观测数据与模型数据分文件输出。
- 修正：DE 目标函数中 center_offset_x 现随 obs_x_flip 取号（与观测同坐标系），修复了预测像位置整体偏移、损失无法下降的问题；将 glafic TOL_ROMBERG_JHK 设为 1.0e-5（精度与速度的折中：比旧值 5.0e-4 更精确，又比 V0.3 的 1.0e-8 快得多）。

English
- Core refactor: the duplicated Differential-Evolution optimization and plotting code scattered across legacy/ is extracted into a unified, backend-agnostic core/ package (legacy/ is kept as a frozen archive; new code never imports it).
  · core/optimize — one DE optimizer; the same code drives glafic (CPU) or Rhongomyniad (GPU). Main lens and sub-structure (point-mass / NFW / King / p-jaffe / …) compose and optimize together in one mixed stack.
  · core/plot — unified triptych, critical curves, and per-iteration animation frames.
  · core/format — a new .dat configuration format + parser (below).
  · core/translate — glafic ↔ glade two-way translation (with a CLI).
- New .dat format: mirrors the legacy inline style, adding {lower, upper} to mark an optimizable dimension (a bare value locks it) and $float / $int placeholders. Mass-like parameters are searched in log10. Multiple files merge by section with global component re-indexing; missing basic values fall back to defaults with a confirmation prompt.
- WebUI rewritten from scratch (webui/; the old web/ is deprecated): top-nav FindImage (default) + Editor. Pick CPU/GPU/Glafic + one or more .dat files; each run opens a real OS terminal, auto-types the command, and the WebUI mirrors that terminal live over SSE in a per-job directory — eliminating the old concurrency bugs. The Editor is a VSCode-like 3-column panel (50px icon rail + drag-resizable tree + tabbed Monaco editor with save/delete), an Explorer over InputFiles (new/open/rename/delete/import/export-translate), and a Template panel that inserts annotated snippets at the cursor.
- Translate: glafic→glade turns opt-matrix-flagged parameters into {v, v} for manual widening; glade→glafic collapses {lower, upper} to a representative value (geometric mean for masses) and splits observation vs model data into separate files.
- Fixes: the DE objective now applies the obs_x_flip sign to center_offset_x (same frame as the observations), fixing a constant x-offset that kept predicted image positions misaligned and the loss from converging; set glafic TOL_ROMBERG_JHK = 1.0e-5 (a precision/speed trade-off: more accurate than the old 5.0e-4, far faster than V0.3's 1.0e-8).
